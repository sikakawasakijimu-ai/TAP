# ColorTap

画面上で指定した色の部分を見つけて、止めるまでタップし続ける Android アプリです。

## 仕組み (軽量化のポイント)

- 画面キャプチャ (MediaProjection) を **1/3 の解像度** で取得し、さらに 2px おきに色を調べます (フル解像度の約 1/36 の処理量)。
- 一致した点を 12px 四方のブロックにまとめ、**一番多く一致したブロックの中心** をタップします。
- タップはユーザー補助サービス (AccessibilityService) で行います。root 不要。
- 画面が変化していないときはスキャンを省略し、前回の結果を使います。
- 外部ライブラリなし (AndroidX も不使用)。

## 使い方

1. APK をインストール (GitHub の Actions → 最新の「Build APK」→ `ColorTap-debug-apk` をダウンロード)。
2. アプリを開き「① ユーザー補助で ColorTap を有効にする」→ ColorTap を ON。
3. 色 (`#RRGGBB`)、許容範囲、チェック間隔、最小サイズを設定。
4. 「② 開始」→ 録画の許可で **画面全体** を選択。
5. 止めるときは、画面に浮かんでいる「■ 停止」ボタン (ドラッグで移動可)、通知の「停止」、またはアプリの「停止」ボタン。

## 設定

| 項目 | 説明 | 初期値 |
|---|---|---|
| 色 | タップしたい色 | `#FF0000` |
| 許容範囲 | R/G/B それぞれ何段階ずれても一致とみなすか (0〜100) | 30 |
| チェック間隔 | 何ミリ秒ごとに画面を調べてタップするか | 300 |
| 最小サイズ | この数以上の点が一致したときだけタップ (ノイズ対策) | 3 |

## 制限

- Android 8.0 (API 26) 以上。
- 開始後に画面を回転すると座標がずれます。回転したら停止→再開してください。
- 開始するたびに録画の許可ダイアログが出ます (Android の仕様)。

## ビルド

```
./gradlew assembleDebug
```
